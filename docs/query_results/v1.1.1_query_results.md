### 测试问题 1：如何正确使用安全带？

### 回答：

根据手册片段中的指导，正确使用安全带的步骤如下：

1. 调节座椅到合适位置。
2. 缓慢拉出安全带，将锁舌插入锁扣中，直到听见“咔哒”声。
3. 使腰部安全带应尽可能低的横跨于胯部。
4. 确保肩部安全带斜跨整个肩部，穿过胸部。
5. 将前排座椅安全带高度调整至合适的位置。捏住调节机构，上下调节安全带高度至合适位置。

注意事项包括：
- 请勿将座椅靠背太过向后倾斜。
- 在系紧安全带前检查锁扣插口是否存在异物（如：食物残渣等），若存在异物请及时取出。
- 安全带必须拉紧，防止松垮，并确保其牢固贴身，无扭曲。
- 切勿将安全带从您的后背绕过、从您的胳膊下面绕过或绕过您的颈部。安全带应远离您的面部和颈部，但不得从肩部滑落。

请务必按照手册中的指导正确使用安全带以确保乘车安全。

### 问题2:胎压报警后应该怎么办？

### 回答

根据手册片段1中的信息，当胎压低报警被激活时，应按照以下步骤操作：

1. 识别对应报警轮胎开始闪烁，并伴有声音报警。
2. 胎压监测系统状态指示灯持续点亮直到报警消除，并且仪表显示屏会弹出提示信息。
3. 在冷态下将轮胎充气至标准胎压值（请参见驾驶员侧B柱上的胎压标签）。
4. 以30 km/h以上的车速行驶几分钟，以便系统更新轮胎压力和温度信息。

遵循上述步骤后，胎压过低的报警应该会解除。如果有任何疑问或情况未得到改善，请联系Lynk & Co领克服务中心寻求进一步帮助。

### 测试问题4:充电时有哪些安全注意事项？

### 回答：

充电时的安全注意事项包括：

- 充电前检查充电电缆，确保没有破损。
- 确保充电端口内没有水或异物，并且金属端子无生锈或腐蚀。
- 在相对安全的环境中进行充电，避免雨淋、水浸和火源附近。
- 不要私自拆卸或改装充电设备及相关端口。
- 选择干燥通风的环境充电，不要在易燃物品附近使用充电设备。
- 阴暗潮湿的场地禁止使用充电线缆。
- 禁止儿童进行充电操作。
- 不要触摸充电口。
- 在雨天没有遮雨棚的情况下，请勿进行充电操作。
- 如果遇到天气突发变化（大风、雨雪、雷暴），应检查充电插头是否牢固且干燥，打雷闪电时禁止接触充电线缆和车身。
- 在充电过程中如发现车辆出现异味，立即停止充电。
- 充电时避免挤压充电线缆。
- 充电结束后，在手湿或站立在积水地面上不要断开充电连接装置。

请严格遵循以上安全措施以确保充电过程的安全。
