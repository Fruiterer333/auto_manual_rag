## 测试问题 1：如何正确使用安全带？

### Answer

要正确使用安全带，请遵循以下步骤：

1. 调节座椅到合适位置。
2. 缓慢拉出安全带，并将锁舌插入锁扣中，直到听到“咔哒”声。
3. 使腰部安全带尽可能低地横跨于胯部。
4. 确保肩部安全带斜跨整个肩部，穿过胸部。
5. 将前排座椅安全带高度调整至合适的位置。捏住调节机构，上下调节安全带高度直至合适。

注意事项：
- 不要将座椅靠背过于向后倾斜。
- 在系紧安全带之前，请检查锁扣插口是否存在异物（如食物残渣等），如有应及时取出。
- 安全带必须拉紧，防止松垮，并确保其牢固贴身，无扭曲。
- 切勿将安全带从您的背部、胳膊下方或颈部绕过。应远离面部和颈部，但不得从肩部滑落。

请按照手册建议操作，以确保最佳的保护效果。

## 测试问题2:胎压报警后应该怎么办？

### Answer

当胎压低报警被激活时，应按照以下步骤处理：

1. 首先停车并检查对应报警轮胎。
2. 如果条件允许，将车辆以30 km/h以上的速度行驶几分钟，使轮胎冷却下来，并重新检测胎压。如果胎压仍然偏低，请参考手册中提供的推荐胎压值进行充气。
3. 确保在冷态下给轮胎充至标准胎压值。
4. 如果在行驶过程中胎压监测系统故障警告灯闪烁一段时间后常亮，应将车辆停放在安全位置，并尽快联系Lynk & Co领克中心进行检查。

以上信息基于手册片段中的建议。请根据实际情况操作，并确保行车安全。

## 测试问题3:儿童锁怎么用？

### Answer

根据手册中的信息，要启用儿童锁，请按照以下步骤操作：

- 对于左后门的儿童锁，使用可分开的机械钥匙，顺时针转动控制器90°。
- 对于右后门的儿童锁，逆时针转动钥匙90°。

按相反方向转动相应控制器可以停用儿童锁。

## 测试问题5:充电时有哪些安全注意事项？

### Answer

在充电时的安全注意事项包括：

- 确保充电电缆没有表皮、外壳破损。
- 在充电前检查并确保充电端口内无水或异物，金属端子未生锈或腐蚀。
- 选择较安全的环境进行充电，避免雨淋和水浸，并远离火源。
- 不要私自拆卸或改装充电设备及相关端口。
- 确保使用干燥、通风的地方充电，不在易燃易爆物品附近充电。
- 避免在阴暗潮湿的地方使用充电线缆。
- 禁止让儿童进行充电作业。
- 充电时不要触摸充电口。
- 在雨天没有遮雨棚的情况下，请勿进行充电操作。
- 如果遇到天气突变（如大风、雨雪、雷暴），应检查充电插头是否牢固且处于干燥状态；在打雷闪电时，禁止触碰充电线缆和车身。
- 如果在充电过程中发现车辆有异味，应立即停止充电。
- 充电时不要挤压充电线缆。
- 充电结束后，在手湿或站立于积水的地面上之前，请勿断开充电连接装置。
