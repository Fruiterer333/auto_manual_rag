### 测试问题1：如何正确使用安全带

### 回答：

为了确保乘车的安全，每位乘员在每次出行前都必须按照正确的方式系紧安全带。具体步骤如下：

​	 1. 请勿将座椅 靠背倾斜得太过向后，以保证安全带能有效发挥作用。

2. 在系紧安全带之前，请检查锁扣插口中是否存在异物（如食物残渣等），如有异物需及时取出。
3. 确保安全带插入与之匹配的锁扣中，并且“咔哒”声响起后，拉动锁舌反方向检查锁扣是否牢固。
4. 安全带必须拉紧并贴身，确保无扭曲，肩部的安全带应从肩部绕过胸部中间至腹部侧面；腰部安全带则应置于大腿处、腹部下方尽可能靠下的位置，避免接触面部和颈部。 请记住，在任何碰撞后，请联系Lynk & Co领克中心检查安全带装置 。

### 回答：

当胎压低报警被激活时，请按照以下步骤操作：
